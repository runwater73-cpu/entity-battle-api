# 本次更新说明

## 生物与首领

- 新增深入天境的狂瞳龙卷：六十五级上下浮动两级，飞行与冰属性，怒火冲天特性，暴风、空气斩、冰冻之风、顺风，携带锐利鸟嘴，单体首领战。
- 全部正式首领默认使用宝可梦战斗。没有前置条件时生成后自动转换；天境与深入天境必须先完成原作对话、勋章交付、合法工具唤醒或攻击确认，原作正式开战后自动转换。
- 向日葵采用相同首领规则，四十五级上下浮动两级，默认生成后自动转换。
- 谜题羊属于普通生物，保留原生人工智能和十六色羊毛任务。原作实际发放任务奖励后，玩家可以自愿转换、捕捉；不会自动转换。捕捉后使用方可梦行为，保留羊毛颜色，不重复任务奖励。
- 暮色领主自动生成已按取消要求停用，训练家由新版整合包的其他模组负责。

## 模型与结算

狂瞳龙卷的控制实体对应一个头部和二十一节身体，身体只用于模型显示，不成为额外群战单位。显示副本不加入世界，不运行原生攻击逻辑。风类攻击绑定张嘴表现与提示粒子。

完整胜利复用来源死亡流程，保留黄铜钥匙、冷空气云、地牢解锁及进度；中断不发通关奖励、不解锁。自动转换的首领中断后继续保持宝可梦。来源战利品保留，战斗携带物不追加掉落。
