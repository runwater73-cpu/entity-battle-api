# 2026-10-10 模型移动与来源回退

- 原生来源模型现在按真实宝可梦上一 tick 到当前 tick 的位移，驱动 Minecraft 的 `WalkAnimationState`。未加入世界的显示副本不会再因为没有原生 `tick` 而只移动不摆腿；铁傀儡的腿部和身体摆动、飞行生物的垂直移动也走同一套计算。
- 客户端在原生模型追踪数据包抵达前，会从宝可梦个体保存的来源标识和外观快照恢复来源。这样永久转换、进化后重新生成和刚加入队伍的个体不会短暂显示空模型，也不依赖数据包到达顺序。
- 开局选择、融合和其他尚未进入世界的客户端界面没有个体 NBT 时，会按 `entitybattle:<来源命名空间>_<实体路径>`（原版为 `entitybattle:<实体路径>`）从当前已安装的实体注册表推导来源；进入世界后仍以服务端 ProfileSync 为准。自定义物种若不使用这套命名，需通过服务端 profile 同步或接入 API 显式提供来源。
- 本次改动只影响客户端显示副本，不把原生 AI、攻击或实体重新加入世界。

仍需要在实际整合包中用铁傀儡、冰晶相关生物和带资源包的队伍界面各走一遍；来源模组的特殊模型若本身依赖额外资源，仍受对应资源包和渲染模组影响。
