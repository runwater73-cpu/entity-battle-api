# 首领战斗机制清单

更新日期：2026-10-08。本表对应当前源码，区分已有实现、可配置的原生规则和仍需开发的设想。实现存在不代表所有整合包组合均已实机验收，测试范围见 [验证记录](../../BOSS_VERIFICATION.md)。

## 已有实现

| 功能 | 当前行为与边界 |
| --- | --- |
| 两种接入方式 | 原生生物模式保留大世界人工智能和交互；直接宝可梦模式使用真正宝可梦实体与方可梦行为 |
| 首领自动转换 | 默认来源资格满足后自动转换；没有前置时生成后转换。天境与深入天境等待原作正式开战 |
| 原作剧情 | 对话、勋章、工具唤醒与攻击确认仍由来源模组执行，自动转换、转换器和快捷挑战共用资格判断 |
| 转换器 | 已接入生物可永久转换；默认引导五秒，可调零至六十秒。无消耗，有创造物品栏，尚无内置合成配方 |
| 原生生物快捷挑战 | 默认关闭，可开启；临时转换并进入对战。未捕捉且未战胜时按来源规则还原 |
| 生命值衔接 | 转换时继承来源生命比例；不保证来源护盾、多部件或所有特殊阶段都等价迁移 |
| 正式物种 | 每种生物独立注册属性、种族值、等级、特性和学习表；捕捉资格单独控制 |
| 队伍与界面 | 复用原生队伍、电脑、资料、治疗、放出收回、头像与模型仓库。来源变种需外观适配 |
| 野生群战 | 复用两个已适配群战模组，最多六个敌方单位。依赖缺失或准备失败时退回单体战斗 |
| 固定开场随从 | 本体加一至五名同种随从。尚不能中途召唤或混合多种随从 |
| 随从等级与四招 | 可设相对首领的等级偏移，以及本场固定四招；未指定时按物种学习表初始化 |
| 战斗持有物 | 本体和随从可分别配置。已有装备不覆盖；首领与临时随从不自动追加装备掉落 |
| 原生六骑士 | 收编同房间原有六骑士，保留身份、编号和武器；整队完整胜利结算一次，残队不自动补齐 |
| 临时成员清理 | 开战前创建明确名单，结束回收，另有孤儿清理。断线、强制终止等仍需对应环境验收 |
| 原生选招 | 复用原生随机或较强人工智能；修正群战空槽目标，没有另外编写首领选招系统 |
| 队友治疗 | 已适配治愈波动；原生人工智能选中后转向合法己方最低生命比例的其他单位，不自疗 |
| 巫妖半血阶段 | 暮光支配：首次半血后本场永久汲取，不再重新获得减伤，没有转阶段换招 |
| 巫妖全伤害分摊 | 魂契分担均分所有本体伤害；余数归巫妖，仆从承受的溢出伤害不再次分配 |
| 有限汲取 | 第二阶段只按攻击造成的对手实际生命损失回复十分之一，不计间接伤害、替身或过量伤害 |
| 哀鸣暴怒 | 累计敌方攻击造成的实际生命损失达到开场最大生命的四分之一后，声音招式威力提高三成 |
| 熔核冷却 | 首次有效开场开启普通晴天；首次敌方冰招真实损伤后清普通晴天，并降低特攻与速度 |
| 亡骸甲胄 | 首次半血且存活后防御提高一级；特性有效时阻挡原生球弹类招式 |
| 中文提示 | 自定义特性名称、说明与触发消息已有中文资源；新增特性仍需配齐语言资源 |
| 动作与粒子 | 招式回调驱动来源显示姿态与特效，不再次执行原生攻击伤害；不同来源需要对应适配 |
| 身体部件 | 狂瞳龙卷身体交互转交控制者，显示副本不加入世界、不充当群战成员；娜迦、九头蛇等亦有专门显示适配 |
| 来源完整结算 | 已登记的复杂来源保存原生状态，完整胜利调用原生死亡后续；普通来源按设定结算战利品与经验 |
| 一次性首领奖励 | 完整胜利发 1 级同物种奖励；有招募球系统时使用该途径，否则进入队伍或电脑，不附本场装备 |
| 中断保护 | 本体先倒下但其余敌人未全灭，不算完整胜利；逃跑或失败不发战利品、奖励和通关进度 |
| 女仆协作 | 已适配当前女仆协作行动协议与空槽目标；不等于任意玩家多人协作已实现 |
| 谜题羊原生任务 | 普通生物，保留原生人工智能与十六色任务。实际领奖后自愿转换捕捉，保留颜色外观，不发首领奖励 |

## 可直接配置的原生规则

| 可配置内容 | 用途与边界 |
| --- | --- |
| 属性与种族值 | 设定耐久、速度和输出定位；同物种玩家奖励也受影响 |
| 等级范围 | 野外随机浮动，不自动改变已有个体等级 |
| 固定四招与学习表 | 野外首领四招可单独指定；玩家奖励按学习等级初始化 |
| 原生特性 | 持久力、纯朴、不服输、锋锐、怒火冲天等复用引擎已有规则 |
| 能力等级变化 | 升降攻防、特攻特防与速度；换下按原生规则处理 |
| 异常与混乱 | 毒、灼伤、麻痹、睡眠、混乱等，免疫与抑制由原生引擎处理 |
| 单体与群攻招式 | 范围、先制、多段、固定伤害等可复用；六位置目标组合仍需实际验证 |
| 防护与辅助 | 守住、反射壁、光墙、帮助、广域防守等，须确认合法目标 |
| 天气与场地 | 晴、雨、雪与场地；雪和冰雹的伤害规则不能混写 |
| 携带物 | 剩饭、树果、属性强化与专属奖杯等；第三方道具效果需安装其来源模组 |
| 捕捉、掉落与经验 | 普通生物可独立配置；正式首领禁捕，来源战利品与装备掉落分别控制 |
| 外观与显示范围 | 复用公共模型仓库；界面大小与世界尺寸分别处理，不为单个界面随意改世界碰撞 |

## 可开发但尚非通用配置的内容

| 机制 | 当前边界 |
| --- | --- |
| 任意半血阶段 | 巫妖和凋灵有专属实现；不能随意填写一个阈值就生成所有阶段 |
| 更多累计伤害阶段 | 可参考哀鸣暴怒，但触发条件、抑制、治疗、换下与新战需要重新定义 |
| 随从死亡强化 | 可以用正式特性实现；须防重新生成随从无限刷新 |
| 回合疲惫或固定循环 | 需定义睡眠、畏缩、失败、跳过和换下，不能直接照搬原作秒数 |
| 混合开场阵容 | 当前只支持一种随从；需要拓展逐成员名单与配置 |
| 逐成员不同设定 | 已可统一覆盖随从四招与道具；逐成员六项和特性尚未实现 |
| 首领与玩家强度分离 | 当前奖励与首领同物种；需正式形态或独立物种，单靠奖励等级低无法削弱种族值 |
| 其他来源小队 | 六骑士已适配；其他小队需要可靠归属、完整来源保存和集体结算 |
| 新专属招式 | 可按方可梦正式招式接口开发，优先复用原生效果；跨物种学习需通用特效降级 |

## 设想与高复杂度内容

| 设想 | 尚未实现的关键部分 |
| --- | --- |
| 中途召唤、复活或换波 | 阵容、请求协议、目标位置、动画队列与奖励要一起变化 |
| 九头蛇独立头部目标 | 需要共享生命、部件死亡、断头再生与目标同步，当前头部只作外观 |
| 多条生命与复活阶段 | 需要正式击倒与胜利规则，不能用直接回满生命替代 |
| 玩家多人协作与弹性难度 | 加入退出、回合等待、同步和奖励分配；女仆兼容不能代替这套流程 |
| 原作机关参与回合战 | 恶魂陷阱、盾牌反弹或环境弱点等需单独设计；原生世界路线仍可保留 |
| 动态异种部队 | 先解决混合开场阵容，再开发中途召唤与成员清理 |

## 持有物与奖励的区别

战斗持有物由接入设定决定，原生战利品由来源模组决定，1 级首领宝可梦是本项目额外奖励。已屏蔽本项目首领的自动装备掉落与临时随从死亡掉落；来源奖杯、钥匙或宝箱仍保留。消耗、偷取与交换道具继续按原生招式规则处理。
