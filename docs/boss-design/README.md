## 共同规则

- 复用方可梦野生对战。玩家队伍最多六只，正常轮换；群战是敌方多个单位同时在场。
- 群战最多六个敌方单位，包含首领；临时随从可配置一至五名。幻影骑士使用原有六骑士小队。
- 正式首领与临时随从不可捕捉。完整胜利发一次 1 级同物种奖励，不附本场装备或临时随从。
- 每个首领和随从都有战斗携带物。自动追加装备掉落已关闭，原作战利品、经验与已适配的死亡后续保留。
- 原生人工智能负责选招，特性负责阶段规则。没有阶段换招或固定出招顺序。
- 模型与动画复用来源显示；原生世界伤害、方块破坏和伤害弹体不在招式中重复执行。
- 自动或永久转换中断后保持宝可梦；临时快捷转换中断恢复来源。未完整战胜不发通关奖励、不解锁。

首领世界模式也可由玩家改成“原生生物”，保留原版战斗选择；普通生物默认仍为原生生物。两种路线均不能绕过来源剧情。

完整中文属性表已同步：[原版与整合包全部一百六十九种生物](../../EntityBattle原版与整合包生物属性表.docx)、[整合包模组九十种生物](../../EntityBattle整合包生物属性表.docx)。两份表都包含当前招式、特性、捕捉规则、首领与随从装备。

每个首领独立保存，不合并成超长文档。查看 [机制清单](功能预设表.md) 可区分已有功能、可配置规则和尚未实现的设想；[流程等级表](../../BOSS_PROGRESSION.md) 与 [验证记录](../../BOSS_VERIFICATION.md) 分别记录等级安排和测试范围。

中文设定用于审阅。真正更改游戏时，需要修改对应物种与接入配置，再构建并安装模组。英文标识、字段和文件路径集中在 [开发接入文档](../../INTEGRATION.md)，不混入各首领设定页。开发辅助脚本会检查十五份设定与源码的一致性。
