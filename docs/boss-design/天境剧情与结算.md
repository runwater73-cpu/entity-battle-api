# 天境与深入天境：剧情、自动转换与原生结算

更新日期：2026-10-08。先完成原作开战条件，再自动成为宝可梦。本页已替换早期“必须手动转换”的设计。

## 剧情必须完成

| 首领 | 原作步骤 | 自动转换时机 |
| --- | --- | --- |
| 滑行魔石 | 使用原模组认可的工具与合法攻击方式唤醒 | 原作正式开战后 |
| 武神女王 | 原生对话交付十枚胜利勋章，随后合法攻击确认开战 | 只交勋章不转换，正式开战后转换 |
| 烈阳巨灵 | 完成原生对话及冷却，最后挑战台词触发开战 | 原作正式开战后 |
| 狂瞳龙卷 | 原生玩家攻击唤醒，原模组执行关门与开战事件 | 原作正式开战后 |

剧情期间仍是原生生物，保留对话、收取勋章、工具校验及人工智能。原作正式开战后无需转换器，自动成为宝可梦；玩家再通过方可梦的派出入口发起对战。自动转换不等于强制把所有玩家立即拉入对战。

友好、准备挑战、正式战斗属于同一来源实体的不同状态，没有为“友好女王”和“敌对女王”另建两种物种。敌对世界行为不代表剧情已完成。和平模式拒绝天境来源转换。

## 各层职责

| 层 | 当前实现 |
| --- | --- |
| 来源资格 | 读取原生正式开战状态与难度；自动转换、转换器和可选快捷挑战共用同一资格判断 |
| 世界生成 | 等来源资格与所在区块可访问后转换，不越过剧情 |
| 来源保存 | 保存原生实体完整状态、身份、位置、地牢与来源辅助实体关系 |
| 原生残留 | 只清理由来源归属确认的攻击与辅助实体，不删除附近无关生物 |
| 宝可梦对战 | 复用方可梦原生野生对战；固定群战复用两个已适配的群战模组 |
| 完整胜利 | 恢复来源并执行原生死亡后续，由来源负责地牢、钥匙、进度与昼夜，不重复补发战利品 |
| 中断 | 自动或永久转换保持宝可梦；临时快捷转换恢复原生来源并调用原作重置。两者都不发胜利奖励、不解锁 |

首领世界模式默认“宝可梦实体”，规定资格满足后的战斗实体。用户也可设为“原生生物”，保留原生世界战斗并自愿使用转换器。此配置不会取消原作资格检查。

默认流程：原生剧情 → 原作正式开战 → 自动成为宝可梦 → 玩家发起对战。逃跑、失败或中断后保留宝可梦；全场胜利才执行原生结算。

## 狂瞳龙卷身体

原作身体是独立生成的生物部件，不是独立宝可梦，也不是群战单位。对身体的转换交互转交控制者；转换时清理同一控制者的身体。模型使用不加入世界的显示副本绘制头部与身体。

宝可梦模式采用单条生命值，不复刻原生逐段击杀或多人额外身体机制。完整胜利复用原作黄铜钥匙与房间解锁。详情见 [狂瞳龙卷](../../DEEP_AETHER_BOSS.md)。

## 验证边界

隔离服务端调用原作对话、勋章交付、合法工具与唤醒入口。原生首回合和完整胜利结算分别检查；完整胜利的强制击倒仅验证生命周期，不代表战斗平衡、自然地牢或所有整合包资源已验收。通过结果以 [验证记录](../../BOSS_VERIFICATION.md) 为准。
