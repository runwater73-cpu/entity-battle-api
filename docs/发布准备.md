# 网站发布准备

更新日期：2026-10-08。当前源码版本为 `0.2.0-beta.1`。

## 当前建议

可以提交公开测试版，文件类型选择 Beta。专项检查和用户已有游玩反馈支持测试发布；自然地牢完整流程、全部组合的显示界面与平衡尚未覆盖，不作为稳定正式版承诺。

## 文件与标签

- 文件：正常构建得到的 `entitybattle-0.2.0-beta.1.jar`，不包含临时诊断类。
- 游戏：Minecraft 1.21.1；加载器：NeoForge；运行时：Java 21。
- 双端安装：服务器和客户端都需要本模组。
- 已核查目标：Cobblemon 1.8.1。模组元数据最低版本对齐 1.8.1。
- 许可证：本项目自有代码与配置使用 MIT，JAR 包内带有许可证。
- 源码与反馈：本 GitHub 仓库及其问题页面。

## 依赖关系

必需：Cobblemon、Kotlin for Forge。内容模组按需安装，不把所有来源模组设置成必需。

首领群战需要同时安装 Asymmetric Battles 和 Horde Encounters；缺少其中一项时走单打。按这些模组自己的声明安装其前置库。

TeamRocket 的融合与女仆协作、两种玩偶模组、Cobbledex 查询和 Xaero 地图都是可选兼容。暮色森林、天境、深入天境、森罗物语暮色等是可选内容来源。未安装来源时对应配置跳过，物种不列为已实现。

## 发布页面资料

已准备 [英文项目介绍](curseforge-description.md)。网站要求英文名称、英文摘要与介绍优先，允许随后加入中文。首领设定与属性表保持中文。

还需提供独立的四百乘四百像素项目图标，并选择准确的游戏版本、加载器、依赖和文件类型；上传 JAR 后由网站审核。已有项目时更新文件，避免创建重复项目。本次只同步 GitHub 源码和准备文件，尚未向 CurseForge 提交项目。

实际游戏截图应反映模组内容。此项目不分发第三方 JAR、模型或贴图，也不声称未核查的闭源模组已经开源或允许再分发。

## 已知边界

- 转换器目前没有内置合成配方，生存获取需作者或整合包提供途径。
- 原生世界人工智能不会自动迁入真正宝可梦，普通生物默认原生模式，复杂来源靠明确适配器保存剧情与死亡后续。
- 原生分段、剑气及动作只作显示，不重复执行世界伤害；不把所有原作首领机制完全复制进回合战斗。
- 旧骑乘资源包覆盖方可梦 1.8.1 新模型可能造成缺少骨骼而断线，见 [已核查案例](troubleshooting/2026-10-08-资源包断线.md)。
